# Orbit F&F — определение устройства

Мини-приложение Telegram для бота закрытого тестирования Orbit (Friends & Family).

Открывается кнопкой «📱 Определить устройство» в боте, считывает данные устройства
(платформа Telegram, User-Agent встроенного браузера, размер экрана) и отправляет их
боту через Telegram (`Telegram.WebApp.sendData`). У страницы нет сервера: она ничего
не хранит и никуда, кроме Telegram, данные не передаёт.

Исходники — в репозитории бота (папка `miniapp/`), сюда публикуются для GitHub Pages.
